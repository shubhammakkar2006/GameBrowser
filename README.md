# 🎮 Game Info App

## 📌 Description

The Game Info App is a simple web application that allows users to search and explore video games using the RAWG API. Users can search for games, filter them by platform, and sort them based on popularity.

---

## 🔗 API Used

* RAWG Video Games API
* https://rawg.io/apidocs

---

## 🚀 Features

* 🔍 Search games by name
* 🎯 Filter games by platform (PC, PlayStation, Xbox, etc.)
* 📊 Sort games by popularity (rating)

---

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* Fetch API

---

## 🧠 Concepts Used

* Fetching data using `fetch()`
* Array methods:

  * `map()` → display games
  * `filter()` → filter by platform
  * `sort()` → sort by rating

---

## ⚙️ How to Run

1. Download or clone the project
2. Open `index.html` in your browser
